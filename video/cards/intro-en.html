Proof of concept · an iPaaS instead of the ETL

webMethods Integration Server
as the ETL, on a star schema

A flat, classic order table (customer, sales rep, product, quantity, unit price, one million lines) turned into a fact table and dimensions, with logging, transactions and real-time monitoring.

  • Source: staging.orders — 999,343 rows, 245 MB (Data Lake style replication of an ERP)
  • Target: fact_sales + dim_date, dim_customer, dim_salesrep, dim_product
  • Engine: flow services + JDBC adapter, transactional sub-flows < 5 min
  • Built and deployed through an API (webmethods-is MCP server), PostgreSQL 16
