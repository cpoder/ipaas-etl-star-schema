webMethods Integration Server
à la place de l'ETL, sur un schéma en étoile

Une table de commandes « classique » (client, commercial, produit, quantité, prix unitaire, un million de lignes) transformée en table de faits et dimensions, avec journalisation, transactions et pilotage en temps réel.

  • Source : staging.orders — 999 343 lignes, 245 Mo (réplication type Data Lake d'un ERP)
  • Cible : fact_sales + dim_date, dim_customer, dim_salesrep, dim_product
  • Moteur : flow services + adaptateur JDBC, sous-flux transactionnels < 5 min
  • Construit et déployé par API (serveur MCP webmethods-is), PostgreSQL 16
